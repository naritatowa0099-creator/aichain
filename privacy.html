プライバシーポリシー

AIチェーン　最終更新日：2026年11月18日

AIチェーン（以下「本ツール」）は、運営者が個人で使うための自動化ツールです。本ツールにおける情報の取り扱いは次のとおりです。

1. 取得する情報

Google アカウントで許可された範囲で、YouTube チャンネルの基本情報（チャンネル名・統計情報）と、動画のアップロードに必要な認証情報（アクセストークン）を取得します。

2. 利用目的

取得した情報は、運営者自身の YouTube チャンネルへの動画のアップロードと、チャンネル情報の確認にのみ使います。

3. 保存場所

認証情報は運営者のパソコン内にのみ保存し、外部のサーバーには保存しません。

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。法令に基づく場合を除きます。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

6. アクセスの取り消し

Google アカウントのサードパーティによるアクセスから、いつでも本ツールへのアクセスを取り消せます。

7. お問い合わせ

GitHub の Issues からご連絡ください。
